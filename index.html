Private backup utility for The Cacao Pair.

This is an owner-operated utility for preparing, encrypting, and storing recovery backups of The Cacao Pair's website data. It is not a customer-facing product or a general-purpose cloud-storage application.

Purpose

Designed for recovery

The planned backup workflow uses PostgreSQL exports, Rclone encryption, and a dedicated Google Drive folder. Backup automation and full database restore testing are still being configured; they are not represented here as already active.

Google Drive access

The utility requests Google's drive.file permission so it can create and manage files used with this application, rather than access all files in a Google account. Google authorization can be revoked through your Google Account settings.

Privacy and data handling

Read our privacy policy for details about the data the utility accesses, encryption, storage, access controls, and retention.

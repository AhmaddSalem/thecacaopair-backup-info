Privacy Policy

Effective: October 9, 2026

The Cacao Pair Backup is an owner-operated utility intended to help protect website data. This notice covers the backup utility's Google Drive authorization and intended storage behavior. The backup automation is being configured and is not yet operating on a daily schedule.

Information accessed

The utility uses Google Drive's drive.file permission to create, locate, read, update, or remove only files used with this application. This permission does not grant blanket access to every file in the connected Google Drive account.

Backup contents

Backups may include business configuration, product details, order records, inventory information, and customer contact or delivery information maintained by The Cacao Pair. Backup files are intended for business recovery, not advertising or profiling.

Use, encryption, and storage

The intended workflow encrypts backup files and filenames using Rclone Crypt before transmitting them to a private folder in the operator's Google Drive. Access credentials and encryption secrets must remain outside the public website and public source repositories. Encryption and an initial sample-file recovery test have been completed locally; a full database restore test is still pending.

Disclosure and service providers

This utility is not intended to sell Google user data, share it with advertisers, or provide third-party access to backups. Google Drive provides storage and Google OAuth provides authorization. GitHub Actions is planned for automated execution; these services process data as needed to provide their infrastructure functions.

Retention and deletion

Backup retention settings are still being finalized. The planned policy is a rolling set of recent backups. The operator may delete backup files from the connected Drive folder and can revoke the application's authorization from Google Account settings at any time. Revoking authorization does not automatically delete files already stored in Drive.

Security limitations

Encryption reduces exposure of backup contents, but no system guarantees complete security. Proper protection also depends on keeping authorization tokens, encryption passwords, and recovery information private and testing restorability.

Changes

This policy will be updated if the backup utility's access, storage, retention, or processing practices change.
